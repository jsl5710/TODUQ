# TODUQ seed set v1

Generated by `toduq generate`. Files:

- `records.jsonl` — accepted annotated turns (one JSON record per line; schema =
  `data/schema/annotation.schema.json`).
- `review_queue.jsonl` — records the judge flagged as `needs_review`/`rejected`.
- `manifest.json` — counts + provenance (generator/judge models, policy, seed).

## Provenance & status

This checked-in build was produced **offline**: template operators (real gold
labels) + `EchoClient` (no LLM paraphrase) + `HeuristicJudge` (deterministic
structural gate). It is a **real, schema-valid artifact** — real SGD turns, real
operators, real gold routing labels, positions, and the full 5-pass provenance —
but it is **not** the final curated set: the surface wording is the plain
template fallback, and the judge is heuristic, not an LLM.

To produce the research-grade curated seed:

```bash
# 1. configs/models.yaml with a real generator + judge (see models.example.yaml)
# 2. regenerate with LLM paraphrase (Pass 3) + LLM judge (Pass 4):
PYTHONPATH=src python -m toduq.cli generate --live
# 3. human-review everything in review_queue.jsonl before promoting to records.jsonl
```

`manifest.json` records which generator/judge actually ran, so a heuristic build
is never mistaken for an LLM-validated one.
